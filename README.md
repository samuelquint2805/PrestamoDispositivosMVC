# 🏗️ PrestamosDispositivosMVC

> **Estado del proyecto:** 🟠 **Versión Beta** > Este sistema se encuentra actualmente en desarrollo. Algunas funcionalidades están siendo corregidas y optimizadas.

Sistema de gestión para el préstamo de dispositivos tecnológicos orientado a la comunidad estudiantil. Permite el control de inventario y la reserva de equipos mediante una arquitectura robusta y segura.

---

## 📋 Descripción del Proyecto

**PrestamosDispositivosMVC** es una solución web que facilita a los estudiantes la reserva de herramientas tecnológicas necesarias para su formación académica. El sistema permite realizar préstamos por periodos flexibles, desde un par de **días** hasta un **semestre completo**.

### Características clave:
* **Consulta de Disponibilidad:** Visualización en tiempo real de los dispositivos aptos para préstamo.
* **Identificación Estudiantil:** Registro y validación mediante el número de carnet.
* **Gestión de Tiempos:** Configuración de reservas para periodos cortos o prolongados.
* **Seguridad:** Sistema de autenticación y autorización basado en **Roles** (Administrador / Estudiante).
